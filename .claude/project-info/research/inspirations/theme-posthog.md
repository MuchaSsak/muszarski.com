# PostHog.com — company website as an operating system

Date: 2026-10-05 · Theme: OS / desktop simulation · URL: https://posthog.com/ · Award: none checked (launched ~Sep 2025)
Screenshots: `img/theme-os-posthog.jpg`, `img/theme-os-posthog-mobile.jpg`

| Aspect | Observation |
|---|---|
| Moves | Illustrated grass wallpaper, desktop icons (Home, Pricing, Docs, Demo, Trash…), content in resizable windows, menu bar, playful cookie banner |
| Practicality [measured] | No gate · ~6.4–7.3 MB, `load` event not reached in 40 s (long-lived media) · content readable immediately · **mobile drops the desktop and shows the page as one framed scroll** |
| Reception [anecdote] | HN: praised fast navigation and standing out; criticised broken right-click/back, not deep-linkable, ~10 fps window dragging on Safari, 20 s load on Firefox Android (https://news.ycombinator.com/item?id=45217269) |
| Borrow (principle) | Themed chrome *around* normal pages; graceful mobile collapse; multiple panels for comparison |
| Don't copy | Full window manager for a personal portfolio — engineering cost and browser-convention fights outweigh the payoff |

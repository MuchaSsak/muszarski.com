## Visual style
- Sky-blue cloud photo background with film grain, a white inset "poster" card with a **sky-filled oval cut-out**, and a glossy **burgundy 3D sculpture** (twisted ribbon/flower) piercing card and background. Crosshair at centre.
- Type mix: a custom rounded display wordmark, **ultra-condensed black caps** ("CRAFTING UNFORGETTABLE DIGITAL EXPERIENCES FOR AMBITIOUS CLIENTS"), a script overlay ("people" over "CLIENTS"), and a pink script monogram "Aj" in a pill.
- Deep plum section backgrounds after scroll, asterisk-ring ornaments, marquee "CREATIVE VISUAL DESIGNER BASED IN INDIA —".

## Navigation
- Desktop: fixed header [measured] with **numbered link groups** (① HOME ② ABOUT ③ WORKS · ① INSTAGRAM ② LINKED IN ③ BEHANCE) plus availability/email/inquiry.
- Mobile: hamburger (two lines). Single long page (~15 screens) plus a `/tetris/` easter egg and a link to the 2022 folio.

## How projects are shown
Mostly links out to **Behance case studies** (Franks Burger, EVOK Systems, Truekind Skincare) [measured]. There are no on-site case-study pages.

## Mobile
Works: logo + hamburger, poster card with the 3D sculpture, giant condensed headline. It ships the same ~10 MB as desktop [measured].

## Preloader / weight [measured]
A 100 % counter appears briefly. DCL 1.1 s, load event 2.3 s on fast desktop, with 10.4 MB already fetched at load and 122 requests.

## Steal
- **Numbered link groups** (① ② ③) in the header: a tidy system for primary vs social links.
- **Availability + email + inquiry link always in the header.**
- **One glossy 3D object breaking a flat poster frame**: a strong 2D/3D layering move.

## Skip
- 10 MB before the load event, which is unusable on mobile networks.
- Outsourcing case studies to Behance, which pushes recruiters off-site.

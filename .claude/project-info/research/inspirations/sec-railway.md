# Railway: product-as-hero, different mobile composition

Date: 2026-10-05 · URL: https://railway.com/ · Section: hero (a) · Screens: `img/sec-railway-desktop.jpg`, `img/sec-railway-mobile.jpg`

- **What works:**
  - A serif H1 "Ship software peacefully" with 2 CTAs over an illustrated night sky.
  - A *real product canvas* (service graph, "Just deployed via GitHub", a cursor on Deploy) rises from below the fold inside a framed card.
  - Mobile replaces the canvas with a 2-column logo grid in the same card.
- **Measured:** H1 in raw HTML; 4.7 MB first load on desktop / 4.1 MB on mobile; 4 sticky elements; doc 13.6 vh.
- **Steal:** the hero visual is a working slice of real work (for us: the PstrykWeb pipeline drawing or a real loop), framed and peeking above the fold. Use a different composition on mobile.
- **Skip:** the logo wall; the heavy illustration weight.
